## Step-by-Step Recording Instructions

### 1. Prepare Dashboard
```
- Log in as Admin
- Navigate to /admin-dashboard
- Clear browser tabs and notifications
- Set zoom to 100%
- Close any pop-ups or alerts
```

### 2. Record Voiceover (First)
```
- Open Audacity or your audio recorder
- Record the full script in one or two takes
- Name file: "melech-sh-voiceover.wav"
- Export as WAV for best quality
```

### 3. Record Screen
```
- Open OBS Studio
- Create a new scene
- Add "Display Capture" source
- Set output to 1920×1080 @ 30fps
- Record the dashboard flows as outlined in scenes above
- Pause between major transitions (helps with editing)
- Export as MP4 (file format: H.264 video, AAC audio)
```

### 4. Edit in DaVinci Resolve
```
1. Import video recording
2. Import voiceover audio
3. Import background music and sound effects
4. Align timeline: voiceover at 2-second mark
5. Add text overlays (see Scene Guide above)
6. Trim and time each scene
7. Add transitions (fade, slide)
8. Color grade if needed (add slight warmth)
9. Export as MP4 (1080p, 30fps, H.264/AAC)
```

### 5. Export & Upload

**Export Settings (DaVinci Resolve):**
```
Format: MP4
Codec: H.264
Resolution: 1920×1080 (16:9)
Frame rate: 30fps
Bitrate: 6–8 Mbps (high quality)
Audio: AAC, 192 kbps, stereo
```

**For Vertical (9:16) — Reels/TikTok:**
```
Format: MP4
Resolution: 1080×1920
Same codec/bitrate as above
```

## Add Captions (Accessibility + Engagement)

**Manual Captions (Using DaVinci Resolve or Online Tool):**
1. Export your video as MP4
2. Use an online subtitle generator (e.g., rev.com or otter.ai)
3. Upload MP4 → Get .srt or .vtt subtitle file
4. Re-import subtitles into editing software
5. Position captions at bottom, use white text with dark outline
6. Export final video with burned-in captions

**Captions to Include:**
```
[00:00] MELECH SH
[00:02] Say goodbye to inventory chaos
[00:04] Live KPI Dashboard
[00:09] Stock Health Monitoring
[00:15] Top Sellers & Quick Reorder
[00:22] Role-Based Access
[00:27] Book a Demo Today
```
