## Image Optimization by Platform

### LinkedIn (1200×627)
- Use: Admin Dashboard Hero Shot
- Optimization:
  - Crop to 1200×627 landscape
  - Add text overlay: "See your inventory in one dashboard"
  - Add LinkedIn watermark/logo
  - Save as `.png` or `.jpg` (JPG for smaller file size)

### Instagram (1080×1080 or 1080×1350)
- Use: KPI Cards + Stock Health + Top Seller (carousel of 3 images)
- Optimization:
  - Crop each to 1080×1080 (square)
  - Add brand colors as borders (dark navy + accent color)
  - Add text overlay: "Live KPIs", "Stock Health", "Top Sellers"
  - Use consistent font (sans-serif, bold)
  - Save as `.jpg` (more compatible with Instagram)

### Facebook (1200×628 or 1200×900)
- Use: Admin Dashboard Hero + Movement Summary (carousel)
- Optimization:
  - Use 1200×628 for feed posts
  - Use 1200×900 for full-width posts
  - High contrast, readable on mobile
  - Add brand logo in corner
  - Save as `.jpg`

### Twitter/X (1024×512 or original)
- Use: KPI Cards or Stock Health Card
- Optimization:
  - 1024×512 recommended (2:1 aspect ratio)
  - Crop tightly, no wasted space
  - High readability at small size
  - Text should be readable at 500px width
  - Save as `.jpg` or `.png`

### WhatsApp (Any size, ~720×1280 recommended)
- Use: Admin Dashboard Hero Shot
- Optimization:
  - Vertical format works best (720×1280)
  - Add text overlay with key benefit
  - Compress slightly to reduce file size (<500KB)
  - Save as `.jpg`

## Image Editing Tools (Free)

If you need to add text overlays or crop:

1. **Canva** (canva.com)
   - Drag-and-drop text + shapes
   - Pre-made templates for all platforms
   - No design skills needed

2. **Figma** (figma.com)
   - Professional design tool
   - Plugins for text overlay
   - Free plan available

3. **Pixlr** (pixlr.com)
   - Simple online editor
   - Good for quick crops and text

4. **GIMP** (gimp.org)
   - Free, open-source Photoshop alternative
   - Full-featured but steeper learning curve

## Image Checklist Before Posting

For each image, verify:

- [ ] Resolution matches platform requirements
- [ ] Text overlays are readable (high contrast, large font)
- [ ] Brand logo or watermark is visible
- [ ] No sensitive data is visible (hide any real customer/product names if needed)
- [ ] Image quality is high (no blurry or pixelated areas)
- [ ] File size is under platform limits (usually <5MB)
- [ ] File format is correct (JPG for Facebook/Instagram, PNG for transparency)
- [ ] Color grading looks professional (no washed out or overly saturated)
- [ ] Text overlay aligns with brand guidelines
- [ ] Image is optimized for mobile viewing
